# Public Configuration

These files are safe examples for the public release. Replace placeholder RSS feeds, PubMed terms, workflow rules, and model names before running the workflow. Keep credentials in environment variables or a local .env file that is not committed.

- rss_sources.json: example RSS feed list
- pubmed_pmc_search.json: example PubMed/PMC query pack
- workflow_rules.json: example A/B/C/D triage rules
- title_translation.config.json: non-credential translation settings
- preference_learning.config.json: non-credential preference-learning settings
